# Responsive Portfolio Website Naufal
### Responsive Portfolio Website Naufal

- Situs web portofolio responsif menggunakan HTML, CSS, dan JavaScript.
- Dilengkapi dengan animasi saat menggulir (scrolling).
- Pengguliran yang mulus (smooth scrolling) di setiap bagian.
- Mengusung tema gelap (dark theme) yang estetis.
- Warna proyek dapat disesuaikan.
- Fitur pengiriman email pada bagian kontak.
- Dikembangkan dengan metodologi *mobile-first* (mengutamakan tampilan seluler terlebih dahulu), kemudian disesuaikan untuk desktop.
- Kompatibel dengan semua perangkat seluler, dengan antarmuka pengguna yang indah dan nyaman.
